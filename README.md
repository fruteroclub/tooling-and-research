# Tooling And Research

Reusable Frutero Club setup guides, runbooks, and research notes for AI tooling,
agent runtimes, VPS builder environments, and model/provider configuration.

## Project Shape

- `docs/runbooks/` - copy-paste operational setup guides.
- `docs/` - reusable research notes and references.
- `code/` - scripts, config generators, and smoke tests.
- `workstreams/` - internOS operational state for active efforts.

## Security

Do not commit API keys, VPS credentials, private endpoints, billing details, or
screenshots that expose account state. Public guides should use placeholders and
private env files for secrets.
